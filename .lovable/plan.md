# Premium editorial redesign

## Direction

Build the selected **Premium editorial layout** as a living broadsheet: DM Serif Display headlines, Fira Sans interface text, warm paper and neutral surfaces, muted editorial red for urgency, and deep teal for secondary interaction. The result stays journalism-first and information-dense while gaining Stripe-level hierarchy, depth, motion, and interaction polish.

## Public publication

- Rework the masthead and navigation into a layered, responsive publication header with refined active states, smoothly animated mobile navigation, and a clearer search entry point.
- Recompose the homepage around a dominant lead story, compact latest-news rail, varied supporting stories, editorial feature bands, ranked most-read content, category strips, and a premium newsletter treatment.
- Replace repetitive card rhythm with asymmetric grids, typography-led story groups, changing image scale, offset rules, and subtle neutral surface transitions.
- Add meaningful load and scroll choreography for headlines, metadata, images, and section boundaries using opacity and transform only.

## Article reading experience

- Add a thin reading-progress indicator.
- Upgrade the article header, metadata tools, bookmark feedback, image/caption reveals, links, and topic interactions.
- Make long-article navigation sticky on wide screens and highlight the current section while scrolling.
- Preserve semantic article markup, accessibility, SEO metadata, and reduced-motion behavior.

## Search and discovery

- Turn search into a focused product interaction with an expressive input state, refined filters, intentional loading/empty states, and smoothly updating results.
- Polish breaking-news, category, link, newsletter, and footer interactions with meaningful red/teal semantics.

## Newsroom CMS

- Upgrade the sidebar, active navigation, dashboard metrics, tables, controls, skeletons, status pills, and editor blocks without reducing information density.
- Add subtle press, focus, loading, success, and state-transition feedback.
- Improve block editing hierarchy and movement feedback while keeping existing publishing behavior intact.

## Design system and performance

- Replace the current font and color tokens with the locked visual system and reusable semantic depth/motion tokens.
- Use restrained borders, layered neutral surfaces, limited shadows, and no decorative gradients or colorful card walls.
- Respect `prefers-reduced-motion`, simplify motion on mobile, and avoid a heavyweight animation library.
- Verify desktop and mobile public pages plus the current sign-in screen, and run focused build/runtime checks.
